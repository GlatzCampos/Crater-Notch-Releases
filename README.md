# Crater Notch — downloads e atualizações

Este repositório contém apenas os pacotes de distribuição e o catálogo assinado de atualizações. O código-fonte é mantido separadamente.

[Baixar a beta 3](https://github.com/GlatzCampos/Crater-Notch-Releases/releases/tag/v0.1.0-beta.3)

macOS 26 ou superior. Pacote universal para Apple Silicon e Intel.

Quem usa a beta 2 precisa instalar a beta 3 manualmente uma última vez. As próximas versões poderão ser instaladas pelo próprio app: o aviso aparece brevemente na ilha e a opção de atualizar permanece no menu do Crater.

Esta beta usa certificado local autoassinado e não é notarizada. Na primeira instalação, pode ser necessário permitir a abertura nos Ajustes do macOS. Atualizações pelo app exigem assinaturas Ed25519 válidas do catálogo e do pacote.
